# Engineering Intelligence · 1.0

Личный навык Codex для владельца и команды существующего проекта. Он помогает разобраться, где реализовано поведение, выдержит ли текущая архитектура новое требование и сколько будет стоить отложить изменение. При аудите Codex читает файлы и выдаёт отчёт в чате. Для системного ограничения записи в Codex CLI также можно открыть проект командой `codex --sandbox read-only`.

## Примеры запуска

Открой нужный проект в Codex и отправь один из запросов.

```text
$engineering-intelligence Проведи архитектурный аудит проекта. Пока ничего не меняй.
$engineering-intelligence Мы хотим добавить ... оцени архитектурные последствия
$engineering-intelligence Хотим добавить ночную выгрузку заказов для одного партнёра. Какой минимум нужен сейчас и когда придётся пересмотреть решение?
$engineering-intelligence Проверь в браузере оформление заказа на телефоне и компьютере. Покажи, что мешает, а что стоит сохранить.
$engineering-intelligence Какие проблемы и согласованные решения по заказам мы записали? Сверь их с текущей версией.
```

| Режим | Пример после имени навыка |
| --- | --- |
| `audit` | Покажи путь заказа от запроса до записи в базу. Приведи файлы и отметь неизвестное. |
| `architecture/plan` | Оцени последствия второго поставщика каталога при команде из двух человек. |
| `implement` | Добавь согласованный фильтр в текущий список заказов и проверь прежний и новый сценарии. |
| `design-review` | Проверь, удобно ли оформить заказ на телефоне. Пока только замечания. |
| `verify` | Проверь локально, что пустой каталог корректно открывается. Укажи, что удалось запустить. |

Название режима можно опустить. Перед крупным решением Codex изучит исходники и спросит лишь о неизвестных, от которых зависит выбор. В рекомендации ищи сегодняшнее действие, ближайшую проверку и измеримый повод пересмотреть архитектуру.

## Дизайн, работа команды и решения владельца

- **Design Intelligence.** Codex сам проходит сценарий в браузере, смотрит мобильные и настольные снимки и отмечает, что помогает или мешает пользователю. При правке сравнивает тот же экран до и после. Полный редизайн требует подтверждённых недостатков и согласования объёма. [Визуальный аудит](references/design.md)
- **Agent Orchestration.** Для простой задачи достаточно одного исполнителя. Когда есть независимые направления, ведущий распределяет их между субагентами, назначает владельцев изменений и приглашает независимого критика для существенных решений по архитектуре, коду и дизайну. В отчёте видны пропуски и нерешённые замечания. [Работа с субагентами](references/orchestration.md)
- **Бизнес-правила.** Если документация и код по-разному трактуют, например, сумму для скидки, Codex покажет разницу и спросит, какое правило действует. Явного ответа владельца достаточно для этой правки.
- **Знания о проекте.** Факты, проблемы, решения и планы сохраняются в отдельном локальном журнале. Следующий сеанс может прочитать их и проверить по текущему проекту. По умолчанию журнал хранится в `~/.local/state/engineering-intelligence/projects/` либо в каталоге состояния XDG. При запрете любых записей итог остаётся в чате. Для автоматической записи нужен Python 3 со стандартной библиотекой. [Журнал проекта](references/project-knowledge.md)

## Установка из архива на Mac

Для первой установки помести `engineering-intelligence-1.0.zip` в «Загрузки» и выполни блок в Терминале. Он проверяет архив и останавливается, если папка навыка уже существует.

```sh
(
  set -e
  skill_zip="$HOME/Downloads/engineering-intelligence-1.0.zip"
  skills_dir="$HOME/.agents/skills"
  /usr/bin/unzip -tq "$skill_zip"
  mkdir -p "$skills_dir"
  mkdir "$skills_dir/engineering-intelligence"
  /usr/bin/unzip -q "$skill_zip" -d "$skills_dir"
)
```

Для замены старой копии на другом Mac сначала перенеси прежнюю папку навыка в резервную папку вне каталога навыков, затем выполни тот же блок. Журнал хранится отдельно. В новом чате Codex введи `$engineering-intelligence`. Если навык ещё не появился в списке, перезапусти Codex. Каталог `~/.agents/skills` соответствует пользовательской области и доступен из разных проектов. [Официальное руководство Codex Skills](https://developers.openai.com/codex/skills/)

Для проверки поведения используй [девять сценариев](evals/scenarios.md) и [рубрику](evals/rubric.md). Архитектура и соответствие реальным требованиям вместе дают 65 из 100 баллов.
